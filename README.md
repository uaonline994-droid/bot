---

## 📦 Встановлення

```bash
pip install -r requirements.txt
```

---

## ⚙️ Налаштування

1. Відкрий `config.py`
2. Встав свій **токен бота** у `BOT_TOKEN`
3. Встав свій **Discord ID** у `OWNER_ID`
4. Запусти бота:

```bash
python bot.py
```

5. На сервері напиши `!setup` — бот автоматично створить всі канали та ролі.

## 📋 Команди

### ⚔️ Модерація
| Команда | Опис |
|---------|------|
| `!варн <@юзер> [причина]` | Видати попередження |
| `!варни <@юзер>` | Переглянути варни |
| `!зняти_варн <ID>` | Зняти варн |
| `!мьют <@юзер> [10m/2h/1d] [причина]` | Замьютити |
| `!анмьют <@юзер>` | Розмьютити |
| `!кік <@юзер> [причина]` | Кікнути |
| `!бан <@юзер> [тривалість] [причина]` | Забанити |
| `!анбан <ID>` | Розбанити |
| `!м'якийбан <@юзер>` | Softban |
| `!очистити [1-500] [@юзер]` | Видалити повідомлення |
| `!профіль [@юзер]` | Мод-профіль |
| `!банлист` | Список банів |

### 📩 Скарги
| Команда | Опис |
|---------|------|
| `!скарга` | Подати скаргу (форма) |
| `!скарги_список [статус]` | Список скарг |
| `!скарга_інфо <ID>` | Деталі скарги |
| `!статистика_скарг` | Статистика |

### 👮 Персонал
| Команда | Опис |
|---------|------|
| `!призначити <@юзер> <1-5>` | Призначити |
| `!зняти <@юзер>` | Зняти |
| `!підвищити <@юзер>` | Підвищити |
| `!знизити <@юзер>` | Понизити |
| `!персонал` | Список персоналу |
| `!ранг [@юзер]` | Перевірити рівень |

### ⚙️ Адміністрація
| Команда | Опис |
|---------|------|
| `!setup` | Авто-налаштування серверу |
| `!оголошення <#канал> <текст>` | Оголошення |
| `!заблокувати_канал` | Lockdown |
| `!розблокувати_канал` | Unlock |
| `!повільний_режим [сек]` | Slowmode |
| `!журнал` | Журнал дій |

## 🔄 Авто-системи

- **Авто-мьют**: 3 варни → 10 хв, 5 → 1 год, 7 → 24 год
- **Авто-бан**: 10 варнів → бан
- **Тимчасові бани/мьюти**: автоматично знімаються через таймер
- **DM-сповіщення**: юзер отримує DM при варні, мьюті, бані
